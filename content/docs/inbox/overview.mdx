The GudDesk shared inbox brings every chat and email conversation into one place, next to any BOT replies, so your team never misses a message.

## How It Works

When a customer sends a message through any channel (chat widget, email, or bot), it appears in your shared inbox as a **conversation**. Each conversation has:

- **A status:** Open, Snoozed, or Closed
- **An assignee:** The team member responsible (or unassigned)
- **Tags:** Free-form labels
- **Priority:** A number from 0 to 3, set through the REST API

## Inbox Views

The conversation list has three tabs:

- **Open**: Conversations that need a reply
- **Snoozed**: Conversations set aside until someone reopens them or the customer replies
- **Closed**: Finished conversations

Next to the tabs, the assignee filter shows all agents, only unassigned conversations, or one teammate's conversations.

## Replying to Conversations

Click any conversation to open the detail view. You can:

- **Reply**: Send a message back to the customer
- **Add a note**: Leave an internal note for your team (customers don't see this)
- **Assign**: Hand the conversation to a specific team member
- **Tag**: Add or remove labels
- **Snooze**: Move the conversation to the Snoozed tab. It reopens when the customer replies
- **Close**: Mark the conversation as finished

## Live collaboration with Pusher keys configured

When you add Pusher keys, teammates viewing the same conversation see each other's avatars in the header, and new messages appear without a refresh. Without Pusher keys, the inbox checks for new messages while the tab is visible: every 4 seconds in the open conversation and every 10 seconds in the conversation list. The same checks take over if Pusher hasn't connected within 8 seconds or fails.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Enter` | Send the reply |
| `Shift` + `Enter` | New line in the reply |
| `/` in an empty reply box | Open canned responses |
| `Cmd` / `Ctrl` + `K` | Open the dashboard command menu |

The inbox does not have conversation search yet.
