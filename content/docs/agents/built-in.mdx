GudDesk does not ship a built-in AI agent yet. One is on the roadmap.

What you can use today:

## Your own agent (BOT replies)

Install an agent in your workspace. GudDesk gives it a webhook and an API key. It hears about new conversations and messages, then replies as BOT. Visitors see those replies in the widget like any other message.

See [Custom agents](/docs/agents/custom-agents) for the install steps.

## REST API and MCP

The REST API covers conversations, customers, articles, companies, segments and workspaces. The [MCP server](/docs/api/mcp) gives MCP clients access to the same workspace.

## Claude assist

If you set `ANTHROPIC_API_KEY`, Claude can:

- Suggest replies
- Summarise conversations
- Read sentiment

On GudDesk Cloud these come with Pro. Self-hosters add their own key.
