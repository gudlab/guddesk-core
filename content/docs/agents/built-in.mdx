GudDesk does not ship a built-in AI agent yet. One is on the roadmap.

## What ships today

**Your own agent.** Install an agent in **Settings > AI Agents**. GudDesk gives it a webhook and an API key. It hears about new conversations and messages and can reply as BOT through the REST API or the MCP server. Visitors see those replies in the widget like any other message.

**AI assist (planned).** Reply suggestions and summaries for your team will ship with GudBot v1. They aren't available on GudDesk Cloud or on self-hosted installs yet.
