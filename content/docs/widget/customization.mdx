---
title: Widget Customization
description: Change the GudDesk chat widget's color, position, welcome message and behavior from the dashboard.
---

You set the widget's look and behavior in the dashboard. The snippet on your site only needs your App ID.

## Dashboard Settings

Go to **Workspace Settings > Widget**. The page shows a preview next to the form. You can set:

- **Display name**: the name shown in the widget header
- **Welcome message**: the first message a visitor sees
- **Primary color**: the color of the launcher, the header and the visitor's messages
- **Position**: bottom-right or bottom-left
- **Require email before chat**: ask visitors for an email address before they can send a message
- **Show GudDesk branding**: the "Powered by GudDesk" line. Pro workspaces can turn it off
- **Offline contact form**: after a set number of minutes with no reply, the widget asks the visitor for their email and message
- **Page visibility**: show the widget everywhere except some URLs, or only on some URLs, using glob patterns

Click **Save**. The widget loads these settings each time it starts, so the change shows up on your site on the next page load.

## Snippet Settings

`window.GudDeskSettings` accepts these keys:

```javascript
window.GudDeskSettings = {
  appId: "gd_pub_xxxxxxxxxxxxxxxx",          // required
  baseUrl: "https://your-guddesk-domain.com", // self-hosted only
};
```

Self-hosted installs with Pusher can also pass `pusherKey` and `pusherCluster`. Colors, position and messages are not read from the snippet. Set them in the dashboard.

## Custom CSS

The widget renders inside a shadow root attached to `#guddesk-widget`, so your page's CSS can't reach its internals. You can position or hide the container itself:

```css
#guddesk-widget {
  /* the host element for the widget */
}
```

To control the chat window from your own code, use `GudDesk.open()`, `GudDesk.close()` and `GudDesk.destroy()`. See [Widget Installation](/docs/widget/installation).
