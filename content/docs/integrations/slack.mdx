---
title: Slack Integration
description: Save a Slack incoming webhook. Automation rules can post to it. Event notifications are not sent yet.
---

<Callout type="warning">
  Automation rules with a **Notify Slack** action post to this webhook. The event settings (new conversations, closes, assignments) are saved, but GudDesk does not send those notifications yet.
</Callout>

## Setting Up

1. In Slack, create an [incoming webhook](https://api.slack.com/messaging/webhooks) for the channel you want to use
2. In GudDesk, go to **Workspace Settings > Integrations**
3. Paste the webhook URL under **Slack** and save
4. Choose the events you want: new conversations, closed conversations and assignments (saved for later, not sent yet)

## Posting from automation rules

Create a rule in **Automations** with the **Notify Slack** action. When the rule runs, GudDesk posts the rule name, the message you set and the visitor's name to the webhook. It does not include the customer's message. If Slack doesn't answer within 5 seconds, the run is marked failed and the next rule still runs.

## What is not available

- Event notifications (new conversations, closes, assignments) are not sent yet
- You can't reply to customers from Slack
- There are no slash commands
- There is no per-tag channel mapping

To get conversation events somewhere else today, use [webhooks](/docs/api/webhooks). Each request is signed, so you can forward events to Slack or any other tool from your own service.
