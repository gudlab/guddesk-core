<Callout type="warning">
  GudDesk does not send Slack notifications yet. You can save the settings below today, and they will be used once sending ships.
</Callout>

## Setting Up

1. In Slack, create an [incoming webhook](https://api.slack.com/messaging/webhooks) for the channel you want to use
2. In GudDesk, go to **Workspace Settings > Integrations**
3. Paste the webhook URL under **Slack** and save
4. Choose the events you want: new conversations, closed conversations and assignments

## What is not available

- Notifications are not sent yet
- You can't reply to customers from Slack
- There are no slash commands
- There is no per-tag channel mapping

To get conversation events somewhere else today, use [webhooks](/docs/api/webhooks). Each request is signed, so you can forward events to Slack or any other tool from your own service.
