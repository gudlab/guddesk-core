Update, October 2026: GudBot is not shipped yet. It's on the roadmap. Today GudDesk works with your own AI agent through the API.

Most "AI-powered" support tools do one thing: they show your customers a help article and hope for the best. If the article doesn't solve the problem, the customer ends up waiting in the same queue they would have been in anyway — just more frustrated.

GudDesk is built for agents that resolve conversations, not just deflect them. The first-party agent is planned. Today you connect your own through the API.

## The Difference Between Deflection and Resolution

**Deflection** is when an AI says "Here's an article that might help" and closes the chat. If the article doesn't answer the question, the customer has to start over.

**Resolution** is when an AI understands the context of the conversation, takes the right action, and confirms the issue is solved — or seamlessly hands off to a human when it can't.

The planned agents aim for resolution. You can already do this with your own agent through the API.

## Planned built-in agents

Three first-party agents are planned:

### GudBot, planned first responder

When it ships, GudBot will handle the first reply. It will read the message, search your knowledge base, and respond. If the customer says that didn't work, it will try another approach or pass the conversation to a human.

### TriageBot, planned router

Not every conversation needs AI. Some need a specific team member. When it ships, TriageBot will route conversations to the right person or team based on content, customer history, and your rules. A billing question from an enterprise customer would go to your account manager. A bug report would land in the engineering queue.

### OnboardBot, planned guide

When it ships, OnboardBot will check in with new users, point them to useful resources, and flag people who look stuck.

## Building Your Own Agents

Until the first-party agents ship, the Agent API lets you build custom agents that integrate with your tools and workflows.

Here's what a basic custom agent looks like:

```typescript
import { GudDeskAgent } from "@guddesk/agents";

const refundAgent = new GudDeskAgent({
  name: "RefundBot",
  trigger: "intent:refund_request",
  async handler(conversation) {
    const order = await lookupOrder(conversation.customer.email);

    if (order && order.isRefundable) {
      await processRefund(order.id);
      return conversation.resolve(
        `Your refund for order #${order.id} has been processed. You'll see it in 3-5 business days.`
      );
    }

    return conversation.escalate("refund-team");
  },
});
```

This agent listens for refund requests, checks if the order is eligible, processes the refund automatically, and only escalates to a human when it can't handle the case.

## Why This Matters

The average customer support interaction costs businesses $5-12 when handled by a human. AI agents that actually resolve issues — not just deflect them — can reduce that cost while improving customer satisfaction.

But the real win isn't cost savings. It's speed. When a customer gets a useful reply in seconds instead of waiting hours, that is the kind of experience that builds loyalty.
